# ChatGPT、Codex 怎么下载和使用？先解决搜不到、打不开、装不了的问题

很多人想试用 ChatGPT 或 Codex，第一步就遇到了困难：

- 华为、小米、OPPO 等手机的应用商店没有对应软件。
- 电脑打不卡chatgtp网页版，或者下载后无法登录。
- 搜到了很多名字相似的“中文版”，不知道哪个是真的。
- 安装了 ChatGPT，却找不到 Codex。

这篇教程按实际遇到的问题来讲。先判断自己卡在哪一步，再选择适合的安装方式。

## 一、先弄清楚：中文界面，不等于中国大陆版本

ChatGPT 可以理解和输出中文，但**支持中文，不代表它在中国大陆的应用商店上架，也不代表中国大陆属于其服务支持地区。**

不要把名称含有“ChatGPT 中文版”“国内版”的应用，直接当成 OpenAI 官方产品。它可能是第三方开发的工具。

开始之前，先认识这几个入口：

- ChatGPT 网页版：[chatgpt.com](https://chatgpt.com/)
- 官方下载页面：[chatgpt.com/download](https://chatgpt.com/download/)
- 地区支持说明：[ChatGPT 支持的国家和地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)
- Codex 使用说明：[官方文档](https://developers.openai.com/codex/)

应用名称、图标和宣传截图都可能被模仿。**从官网下载页进入应用商店，并确认发布者为 OpenAI，更容易找到正确的应用。**

## 二、为什么别人能下载，你却搜不到？

安装前，要分别检查四个条件。

| 检查项目 | 常见情况                        | 会出现什么问题           |
| ---- | --------------------------- | ----------------- |
| 网络访问 | 当前网络无法连接官网或相关服务             | 网页打不开、下载失败、登录一直转圈 |
| 商店地区 | 当前 Apple 或 Google 商店地区不提供应用 | 搜不到，或提示所在地区不可用    |
| 设备条件 | 系统版本、硬件或必要组件不符合要求           | 无法安装，或提示设备不兼容     |
| 账号条件 | 服务地区、账号状态、套餐或管理权限不符合要求      | 安装成功，但不能登录或缺少功能   |

大家常说的“梯子”，通常只涉及网络访问这一层。

\*\*网络能够连接，不会自动改变应用商店地区，也不会自动获得服务资格或付费功能。\*\*因此，不能把“准备一个网络工具”当成完整安装教程。

如果你目前无法访问官方服务，第一步应当是核实网络和服务支持条件。反复重装应用通常不能解决这些问题。

## 三、苹果手机：国区 App Store 搜不到怎么办？

### 第一步：从官网打开商店链接

打开 [官方下载页面](https://chatgpt.com/download/)，点击 iOS 下载入口。

这样可以直接检查官方应用在你当前商店中的状态，比只搜索“AI”“ChatGPT 中文版”更准确。

### 第二步：看清楚具体提示

**提示“你所在的国家或地区尚未提供此 App”**

这通常涉及商店地区，并不是手机损坏。改变手机的系统语言，也不会让应用自动上架。

Apple 的商店地区与用于“媒体与购买项目”的 Apple 账户有关。只有在你符合 Apple 的地区要求、实际有资格使用相应商店时，才按 Apple 官方说明处理账户地区问题。

**提示“需要更新系统”或“设备不兼容”**

打开应用商店页面，查看当前的系统和设备要求。先判断手机能否更新，再决定是否安装。

**能够安装，但打开后无法登录**

继续检查网络连接、服务支持地区和账号提示。商店可以下载应用，并不代表服务端一定允许使用。

### 第三步：安装并验证

符合下载和使用条件后：

1. 确认应用发布者为 OpenAI。
2. 点击获取，等待安装完成。
3. 打开应用，按页面提示注册或登录。
4. 新建对话，发送：“请用中文介绍你的三个常用功能。”
5. 能正常收到回答，才算完成首次使用验证。

不要为了下载应用，把自己的 Apple 账户密码或验证码交给陌生人代操作。

## 四、安卓手机：自带应用商店没有怎么办？

华为、小米、OPPO、vivo 等手机的自带应用商店，并不等于 Google Play。**在自带商店搜不到，不代表你搜索的方法错了。**

### 第一步：检查有没有可正常使用的 Google Play

打开 [官方下载页面](https://chatgpt.com/download/)，点击 Android 入口。

如果页面转向 Google Play，再检查：

- 手机是否具有可用的 Google Play 及必要服务。
- Google Play 账号所在地区是否提供该应用。
- 商店页面是否显示设备兼容。
- 网络是否能正常连接下载和登录所需的服务。

### 第二步：根据页面状态处理

**手机没有 Google Play**

官网跳转到 Google Play，并不会自动给手机补齐相关服务。不同品牌和系统情况差异很大，不能承诺所有手机都能通过同一套步骤安装。

**Google Play 显示所在地区不可用**

这是商店地区问题。换一个搜索词、清理缓存或反复下载，一般不能解决地区上架限制。

**显示设备不兼容**

以商店列出的当前要求为准，检查系统版本及设备支持情况。

**能安装，但启动或登录失败**

安装包和服务连接是两个环节。即使装进手机，也仍需要符合账号、网络和服务地区条件。

### 第三步：验证首次使用

满足条件后，从官方链接进入的商店页面安装，确认发布者为 OpenAI。登录后发送一个简单问题，检查能否正常获得回复。

如果改用第三方 APK，要注意：它可能存在版本过旧、来源不明、无法自动更新等问题。**安装 APK 本身也不会解除网络或地区限制。**

## 五、电脑：先验证网页版，再决定是否安装

电脑端建议先做一次简单检查：

1. 用浏览器打开 [chatgpt.com](https://chatgpt.com/)。
2. 看网页能否正常加载。
3. 按提示注册或登录。
4. 发一个简单问题，确认能够收到回答。

如果网页版都无法连接，先判断是网络问题、服务地区问题，还是账号问题。不要把安装桌面客户端当成解决连接问题的方法。

### Windows 和 Mac 的安装步骤

确认可以使用服务后：

1. 打开 [官方下载页面](https://chatgpt.com/download/)。
2. 选择当前提供的、适合自己系统的下载入口。
3. 如果跳转到系统商店，检查发布者、设备兼容性及系统要求。
4. 如果提供安装文件，按官方安装提示完成操作。
5. 打开应用，使用自己的账号登录。
6. 新建对话，发送测试问题。

如果商店搜不到应用，先从官网链接进入，再查看是否为地区或设备限制。不要仅凭搜索结果下载名称相似的软件。

## 六、Codex 到底在哪里？为什么安装后没有？

Codex 主要用于协助开发网页、处理代码和完成项目任务。它有桌面、编辑器扩展、命令行及云端等不同使用方式。

截至本文整理时，**官方下载页面已提供包含 ChatGPT 和 Codex 的桌面应用入口**，并提示旧版 Codex 应用用户可以更新到 ChatGPT，再打开其中的 Codex。

因此，不必只在手机商店搜索一个名叫“Codex”的独立应用。

电脑端可以按以下顺序检查：

1. 从官方下载页安装或更新桌面应用。
2. 登录自己的账号。
3. 在应用中查找 ChatGPT 与 Codex 的切换入口。
4. 如果没有看到，核对当前版本、账号可用功能和官方说明。
5. 如果是单位或学校账号，再检查管理员是否限制了相关功能。

\*\*下载桌面应用，不等于所有账号都自动拥有相同的 Codex 功能和额度。\*\*是否可用，以账户内显示和当前官方说明为准。

手机端入口与电脑端可能不同，不要把电脑教程中的按钮位置直接套用到手机上。

## 七、装好以后，第一次应该怎么用？

### 用 ChatGPT 完成一个小任务

新建对话，输入：

> 我是 AI 新手。请帮我写一份一周学习计划。我每天有 30 分钟，希望学习如何用 AI 写文章。请用表格列出每天的任务，并给出一个可以直接复制的提问示例。

如果结果太复杂，继续说：

> 把任务改得更简单，每天只安排一件事，并解释怎么检查自己是否完成。

提问不必一次写得完美。说明需求、查看结果、提出修改，就能逐步得到更合适的答案。

### 用 Codex 制作一个简单网页

建议在电脑上操作：

1. 新建一个专门用于练习的空文件夹。
2. 打开 Codex，按界面提示选择这个文件夹。
3. 新建对话，输入：

> 我不会编程。请帮我制作一个中文个人介绍网页，包含自我介绍、兴趣爱好和作品展示。页面需要适合手机阅读。请先说明简短方案，再创建文件，完成后告诉我如何预览。

完成后，打开预览，继续提出修改：

> 把主色调改成浅蓝色，增大正文字号，把作品展示改成三张卡片。

第一次练习使用空文件夹，方便检查它创建了什么。需要发布到互联网时，再单独确认发布内容和发布位置。

## 八、遇到问题，按这个表检查

| 你遇到的情况        | 优先检查什么                     |
| ------------- | -------------------------- |
| 官网完全打不开       | 网络连接、服务可达性                 |
| App Store 搜不到 | 官网链接、商店地区、设备兼容性            |
| 安卓自带商店没有      | 是否有官方渠道及可用的 Google Play 环境 |
| 安装时提示不兼容      | 当前系统与硬件要求                  |
| 安装成功但登录失败     | 网络、服务地区、账号状态和错误提示          |
| 登录成功但没有 Codex | 应用版本、入口位置、账号权限及套餐          |
| 提示达到使用上限      | 账户额度及页面说明                  |
| 找到许多收费“中文版”   | 发布者是谁、是否第三方、费用付给谁          |

排查时，记下完整错误提示，比只说“用不了”更容易找到原因。需要向他人求助时，隐藏邮箱、验证码和其他私人信息。

## 九、目前不具备安装条件，还能先学什么？

如果当前不满足官方服务的访问和使用条件，可以先用你所在地区能够正常提供服务的 AI 工具，练习这些通用方法：

- 清楚描述目标和读者。
- 提供必要材料和示例。
- 指定字数、格式和语气。
- 对结果提出具体修改。
- 核对重要事实与引用来源。

这些技巧以后使用 ChatGPT 或 Codex 时同样有帮助。第三方工具的身份、功能和收费应单独了解，不能因为它支持中文或能聊天，就把它当成 OpenAI 官方产品。
